# 🏁 Corrida do Matheus

Jogo de kart para celular e computador, feito de presente para o Matheus.

**Jogar:** https://orafaelcostaoficial.github.io/corrida-do-matheus/

- Corridas em 8 fases, Copas, Estilo Livre e Enduro
- Criador de pistas
- Garagem e loja (moedas e diamantes salvos no aparelho)
- Instalável (PWA) e funciona sem internet
